**Cracks Pollos y Arroces** es una solución web interactiva desarrollada para el sector gastronómico. El proyecto está enfocado en optimizar la experiencia de usuario (UX) y la usabilidad (IHC), permitiendo a los clientes explorar el menú digital, gestionar su pedido mediante un carrito de compras dinámico y realizar el seguimiento en tiempo real de sus órdenes.

*******************************************************************************************************************************************

## 🎯 Características Principales

- Catálogo Digital Interactivo: Visualización de productos organizados por categorías (pollos, arroces, combos y bebidas) con imágenes optimizadas y descripciones detalladas.
- Carrito de Compras Dinámico: Módulo en JavaScript para agregar, eliminar y modificar cantidades de productos con cálculo automático de totales.
- Rastreador de Pedidos (Tracking):Interfaz visual para el seguimiento del estado del pedido en tiempo real (Recibido ➔ En preparación ➔ En camino ➔ Entregado).
- Diseño Responsivo e IHC: Maquetación orientada a estándares de usabilidad, accesibilidad web y navegación fluida en dispositivos móviles y de escritorio.

*******************************************************************************************************************************************

## 🛠️ Tecnologías Utilizadas

- HTML5: Estructura semántica de la aplicación.
- CSS3: Estilos personalizados, maquetación con Flexbox/Grid y diseño adaptativo (Responsive Design).
- JavaScript (ES6+): Lógica interactiva para la gestión del carrito, manipulación del DOM y eventos de usuario.
